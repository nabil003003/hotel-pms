Pages préliminaires

Page de garde

Elle doit contenir :

Nom de l’établissement
Filière / formation
Intitulé du rapport
Thème du stage
Nom et prénom de l’étudiant
Entreprise d’accueil
Encadrant pédagogique
Encadrant professionnel

Le modèle commence directement par le titre du projet, les auteurs, les encadrants et l’année universitaire.

Dédicace

Une page maximum.

Le modèle utilise une dédicace personnelle adressée notamment aux parents et à la famille.

Remerciements

Une page maximum également.

Tu peux remercier dans cet ordre :

entreprise d'accueil
encadrant professionnel
encadrant pédagogique
équipe / collègues
établissement
famille et proches

Le modèle consacre une section distincte aux remerciements et remercie les encadrants ainsi que les personnes ayant contribué au travail.

Résumé

Environ 150–250 mots.

Il doit répondre rapidement à :

Quel était le contexte ?
Quel problème ?
Quel objectif ?
Quelle solution ?
Quelles technologies ?
Quel résultat ?

Le modèle présente précisément le projet, ses objectifs, la technologie, la méthodologie et les résultats principaux dans cette partie.

Abstract

Traduction anglaise du résumé.

Mots-clés

5 à 10 mots-clés.

Glossaire

Uniquement les termes techniques réellement utilisés.

Le modèle possède un glossaire sous forme de tableau avec le terme et sa définition.

Liste des figures

Toutes les figures numérotées avec leurs pages.

Le modèle utilise une numérotation du type Figure 1-1, Figure 2-3, Figure 4-17, etc.

Liste des tableaux

Même principe pour les tableaux. Le modèle utilise Tableau 2-1, Tableau 3-1, etc.

Table des matières

Automatique, avec une hiérarchie claire.

Règles de rédaction à suivre

Le modèle utilise une numérotation hiérarchique du type 1., 1.1, 1.2, 1.2.1, etc.

Je te conseille donc de conserver exactement cette logique :

Chapitre 1
1.1
1.2
1.2.1
1.2.2
1.3
1.4

Chapitre 2
2.1
2.2
2.3
...

Pour les figures :

Figure 1-1
Figure 1-2
Figure 2-1
Figure 2-2
...

Pour les tableaux :

Tableau 2-1
Tableau 2-2
Tableau 3-1
...

C'est exactement le système de numérotation utilisé dans le modèle.

Pour chaque chapitre

Utilise toujours :

Chapitre X : Titre

X.1 Introduction

...

X.n Conclusion

Le modèle suit bien cette logique pour ses différents chapitres.

Pour les paragraphes

Évite de faire uniquement :

définition de technologie
logo
définition de technologie
logo

C'est justement la faiblesse principale du chapitre 3 du modèle : il présente beaucoup de définitions générales de technologies.

Pour ton rapport, fais plutôt :

Technologie → rôle dans le projet → raison du choix → intégration dans l'architecture.

Cela donnera un rapport beaucoup plus personnel et beaucoup plus professionnel.
